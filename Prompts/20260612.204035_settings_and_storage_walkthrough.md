# Walkthrough - Settings & Storage Overhaul

We have successfully overhauled the settings storage model and backup directories to run directly in shared storage with All Files Access.

## Changes Made

### build.gradle
- Added the Google Gson dependency: `com.google.code.gson:gson:2.10.1` for JSON serialization.

### AndroidManifest.xml
- Added the `<uses-permission android:name="android.permission.MANAGE_EXTERNAL_STORAGE" />` permission to allow raw file access to external storage on Android 11+ devices.
- Enabled `android:requestLegacyExternalStorage="true"` for compatibility on Android 10.

### Settings Model (AppSettings.java)
- Created [AppSettings.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/models/AppSettings.java) with configuration fields:
  - `backupDirPath` (defaults to `/sdcard/Vypeensoft/APK_Backup_Restore/backup/`)
  - `showSystemApps` (defaults to `false`)
  - `defaultSortPreference` (defaults to `"name"`)
- Saves/loads configurations to the JSON file at `/sdcard/Vypeensoft/APK_Backup_Restore/settings/settings.json`.

### Deprecating StorageManager
- Replaced the Scoped Storage tree document resolver `StorageManager.java` with a placeholder stub.

### Managers & Repositories
- Updated [ApkBackupManager.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/utils/ApkBackupManager.java) to write extracted APK files directly to the custom path in `AppSettings.load().backupDirPath` using standard Java stream writers.
- Simplified [ApkRestoreManager.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/utils/ApkRestoreManager.java) to launch standard PackageInstaller directly using FileProvider URIs of the local backup files.
- Refactored [BackupRepository.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/repositories/BackupRepository.java) to scan the custom directory directly via `File.listFiles()` and parse package archives locally.
- Updated `PermissionManager.java` to support checking and launching setting intent for `MANAGE_EXTERNAL_STORAGE`.

### UI Changes
- Updated [MainActivity.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/activities/MainActivity.java) to request "All Files Access" on startup.
- Redesigned [fragment_settings.xml](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/res/layout/fragment_settings.xml) to remove the Dark Theme toggle, and added an Outlined TextInputLayout with a Save button for the custom backup path.
- Updated [SettingsFragment.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/fragments/SettingsFragment.java) to load and save settings to the JSON settings file on SD card.
- Modified `InstalledAppsFragment.java` to load preference toggles from `AppSettings`.
