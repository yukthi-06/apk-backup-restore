# Walkthrough - Restore Button Text and Back Navigation Icon Updates

This walkthrough documents the UI updates to show "Restore..." as the button label and to display a back navigation icon on the toolbar in the Restore screen.

## Changes Made

### 1. Layout Updates
- **File modified**: [fragment_installed_apps.xml](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/res/layout/fragment_installed_apps.xml)

### 2. Main Activity / Navigation Toolbar Updates
- **File modified**: [MainActivity.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/activities/MainActivity.java)
  - In `showBackupsFragment()` (the Restore view), configured the support action bar to display the back navigation home icon (`setDisplayHomeAsUpEnabled(true)`), locked the side navigation drawer shut, and set `toolbar.setNavigationOnClickListener` to trigger `showInstalledFragment()`.
  - In `showInstalledFragment()`, unlocked the drawer, turned off the back icon, re-added the drawer listener/toggle, and re-bound the navigation click listener to open the side menu drawer.
