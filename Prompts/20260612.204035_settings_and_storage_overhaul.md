# Settings & Storage Overhaul

This plan outlines the steps to overhaul settings and backup storage:
1. Store all settings (including backup path, show system apps toggle, and sort preference) in a JSON file at `/sdcard/Vypeensoft/APK_Backup_Restore/settings/settings.json`.
2. By default, backups should be stored at `/sdcard/Vypeensoft/APK_Backup_Restore/backup/`.
3. Allow the user to configure this directory path directly in the settings UI.
4. Remove the "Dark Theme" option from Settings.
5. Use `MANAGE_EXTERNAL_STORAGE` permission to allow direct Java `File` access to the SD card.

## User Review Required

> [!IMPORTANT]
> This change migrates backup storage from Scoped Storage SAF `DocumentFile`s to direct Java `File` operations under the `/sdcard/Vypeensoft/APK_Backup_Restore` directories. The app will prompt for "All Files Access" (`MANAGE_EXTERNAL_STORAGE`) on startup.
