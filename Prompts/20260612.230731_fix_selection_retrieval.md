# Walkthrough - Batch Selection Retrieval Fix

This walkthrough documents the fix to ensure selected list items are correctly identified during batch actions.

## Root Cause
Previously, batch actions (e.g. backup, uninstall, reinstall, delete) queried the lists from the ViewModels (`viewModel.getInstalledApps().getValue()` and `viewModel.getBackupApps().getValue()`). Since these list instances can be re-instantiated or decoupled from active checkbox status changes occurring inside the recycler adapters, the checked states of the items were not being read.

## Changes Made

  - Added helper method `getSelectedApps()` which queries the active adapter list directly to return only selected items.
