# Walkthrough - Sort By Menu Dialog Styling Updates

This document records the changes to make the Sort By Dialog (and all Material Alert Dialogs) display black text on a white background.

## Changes Made

### Themes Configuration
- **File modified**: [themes.xml](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/res/values/themes.xml)
- Declared a new theme overlay `CustomAlertDialogTheme` parented on `ThemeOverlay.Material3.MaterialAlertDialog`.
- Configured style settings for `CustomAlertDialogTheme`:
  - `colorSurface` -> `@android:color/white` (forces solid white background)
  - `colorOnSurface` -> `@android:color/black` (forces text, titles, list item text to black)
  - `colorOnSurfaceVariant` -> `@android:color/black` (forces description/sub-texts to black)
  - `android:textColorPrimary` -> `@android:color/black` (ensures base text colors are black)
  - `colorPrimary` -> `@color/primary` (keeps buttons using the Google green color)
- Applied the style to the main app theme under `materialAlertDialogTheme`.
