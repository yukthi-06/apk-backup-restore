# User Prompt
Create a complete Android application named **"APK Backup & Restore"** using **Java (NOT Kotlin)** and Android SDK.

## Objective

Build a modern Android app that allows users to:

1. View all installed applications.
2. Extract and backup APK files of installed applications.
3. Save APK files to a user-configurable backup folder.
4. Restore/install APK files from backups.
5. Uninstall installed applications.
6. Browse existing APK backups.
7. Share backed-up APK files.

## Technical Requirements

### Language & Platform

* Use Java exclusively.
* Minimum SDK: Android 8.0 (API 26).
* Target latest Android SDK.
* Android Studio project.
* Use AndroidX libraries.
* Follow MVVM architecture where practical.
* Use Material Design 3 UI components.

## Technical Details & Strategy

### 1. Storage Access Framework (SAF)
- To configure the backup folder dynamically and comply with modern Scoped Storage guidelines, we will use the **Storage Access Framework** via `Intent.ACTION_OPEN_DOCUMENT_TREE`.
- If the user has not selected a folder, we will fallback to `context.getExternalFilesDir("Backups")` as the default location.
- For files created in SAF trees, we will use the `DocumentFile` API, opening OutputStreams via `ContentResolver.openOutputStream(Uri)`.

### 2. Package Visibility (Android 11+)
- In the `AndroidManifest.xml`, we will include a `<queries>` block targeting launcher applications to ensure that `PackageManager.getInstalledPackages()` retrieves the full set of installed applications.

### 3. FileProvider & Installing APKs
- To restore/install APKs, we will configure a `FileProvider` to safely share files with the package installer.
- We will trigger the installation flow using `ACTION_VIEW` and grant read permissions to the installer. We will also check `canRequestPackageInstalls()` and prompt the user to enable "Install Unknown Apps" if not granted.

### 4. Material Design 3 UI
- Use dynamic Material Design 3 theme styling, a bottom navigation view with 3 tabs, modern cards with hover/click animations, and robust search/sort dialogs.
