### 4. Logic and Sequential Processing
- **File modified**: [MainActivity.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/activities/MainActivity.java)
  - Removed old bottom navigation references and added helper methods to transition fragments.
- **File modified**: [InstalledAppsFragment.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/fragments/InstalledAppsFragment.java)
  - "Backup" button: Iterates through selected apps, invoking sequential extraction/backups with a progress dialog.
  - "Uninstall" button: Creates a queue of selected package names and uninstalls them one by one. Resuming the fragment checks the status of the current package in the queue to trigger the next uninstallation request.
  - "Restore" button: Transitions to the backups fragment view.
- **File modified**: [BackupsFragment.java](file:///x:/Projects_X/0_Active/8_Android_APK/04_Early_Stage/APK_Backup_Restore_APK_GITHUB/app/src/main/java/com/vypeensoft/apkbackuprestore/fragments/BackupsFragment.java)
  - "Install" button: Iterates through selected backups, invoking sequential installation processes.
  - "Delete" button: Prompts for confirmation and deletes selected backup files in a batch.
  - "Back" button: Transitions back to the installed apps fragment view.
