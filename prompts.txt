Here's a single, comprehensive prompt you can give to an AI coding agent:

Create a complete Android application named **"APK Backup & Restore"** using **Java (NOT Kotlin)** and Android SDK.

## Objective

Build a modern Android app that allows users to:

1. View all installed applications.
2. Extract and backup APK files of installed applications.
3. Save APK files to a user-configurable backup folder.
4. Restore/install APK files from backups.
5. Uninstall installed applications.
6. Browse existing APK backups.
7. Share backed-up APK files.

## Technical Requirements

### Language & Platform

* Use Java exclusively.
* Minimum SDK: Android 8.0 (API 26).
* Target latest Android SDK.
* Android Studio project.
* Use AndroidX libraries.
* Follow MVVM architecture where practical.
* Use Material Design 3 UI components.

### Core Features

#### 1. Installed Apps Screen

Display all installed applications with:

* App icon
* App name
* Package name
* Version name/version code
* APK size
* System app indicator
* Search functionality
* Sort by:

  * Name
  * Size
  * Install date
  * Update date

Actions per app:

* Backup APK
* Share APK
* Open App Info
* Launch App
* Uninstall App

#### 2. APK Backup Functionality

When user taps Backup:

* Extract APK from installed application source directory.
* Copy APK to configured backup folder.
* Generate meaningful filename:

AppName_VersionName.apk

Example:
WhatsApp_2.25.10.apk

Requirements:

* Show progress indicator.
* Handle storage errors gracefully.
* Avoid overwriting existing backups unless user confirms.
* Display success/failure message.

#### 3. Backup Management Screen

Display all backed-up APK files:

* APK icon
* App name
* APK filename
* Version
* APK size
* Backup date

Actions:

* Install APK
* Share APK
* Delete Backup
* View APK Details

#### 4. APK Restore / Install

Implement APK installation using:

* FileProvider
* ACTION_VIEW intent
* Proper URI permissions

Requirements:

* Support Android 8+ package installation restrictions.
* Detect and guide user to enable "Install Unknown Apps" permission when required.

#### 5. App Uninstall

Allow uninstalling any non-system application.

Implementation:

* Use ACTION_DELETE intent.
* Show confirmation dialog before uninstall.
* Refresh app list after uninstall.

#### 6. Configurable Backup Folder

Settings screen must allow:

* Select backup folder using Storage Access Framework.
* Persist selected folder URI permissions.
* Display current backup location.
* Restore default location.

Default backup location:
Internal Storage/APK_Backups/

#### 7. Runtime Permissions

Handle:

* Storage permissions where applicable.
* Android 10+ scoped storage requirements.
* Android 11+ package visibility requirements.
* Android 13+ media/storage behavior.

#### 8. APK Metadata Extraction

Extract and display:

* Package name
* Version name
* Version code
* Minimum SDK
* Target SDK
* APK size
* Application label

Use PackageManager APIs.
